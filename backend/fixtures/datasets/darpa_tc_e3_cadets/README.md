# DARPA TC E3 CADets Minimal Test Fixture

This directory contains a minimal test fixture for `DarpaTcE3CadetsAdapter`.
It is intentionally tiny and is not the full DARPA TC E3 CADets dataset.

The records only exercise representative field mappings used by unit tests:
process activity, network activity, and file activity. Do not use this fixture
for dataset evaluation, performance reporting, IOC coverage, or claims about
the original DARPA corpus.
